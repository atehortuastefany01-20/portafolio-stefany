DE LA IDEA AL CÓDIGO

Una buena solución empieza con una buena pregunta.

  1. Entender

    Definir el objetivo, las personas que usarán la web y la información que necesitan encontrar.

  2. Explorar

    Investigar referencias y organizar el contenido para darle una identidad propia.

  3. Diseñar

    Probar la estructura, las jerarquías y la navegación antes de construir la interfaz.

  4. Desarrollar

    Convertir el diseño en HTML, CSS y JavaScript con componentes y contenido separados.

  5. Verificar

    Revisar enlaces, video, teclado y tamaños de pantalla antes de publicar y seguir mejorando.

Este portafolio lleva ese proceso a la práctica.
